# ViewModel Practice
## 🇹🇷 Uygulamayı Çalıştırmak

Bu repo iki farklı branch içerir:  
`starter` (temel hali) ve `viewmodel` (gelişmiş hali).

Eğer starter branch'ini çalıştırmak isterseniz:

```bash
git clone https://github.com/tugbaguney/CounterAppViewModel.git
cd CounterAppViewModel
git checkout starter
 ```

Daha sonra Android Studio ile açarak projeyi çalıştırabilirsiniz.

💡 ViewModel ve StateFlow eklemeleri hakkında daha fazla bilgi için Medium yazımı okuyabilirsiniz.

👉 Medium'da Oku: https://medium.com/@hotreloadiaries

## 🇬🇧 How to Run the App
This repository includes two branches:
starter (basic version) and viewmodel (enhanced version).

To run the starter branch:
```bash
git clone https://github.com/tugbaguney/CounterAppViewModel.git
cd CounterAppViewModel
git checkout starter
 ```
Then open the project in Android Studio and run the app.

💡 For detailed explanation about integrating ViewModel and StateFlow, check out my Medium post.
